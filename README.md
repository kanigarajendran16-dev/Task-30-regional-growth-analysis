# 📊 Regional Growth Analysis

### VEDA Technology – Task 30 | Data Analytics

Regional Growth Analysis is a data analytics project developed as part of the VEDA Technology internship program.

The project analyzes regional sales performance over time and compares growth rates between different regions using SQL, Python, Excel, and interactive data visualization.

---

## 📌 Project Overview

The objective of this project is to compare regional growth rates over consistent time periods and identify important business insights from regional sales data.

The analysis focuses on:

- Regional sales performance
- Month-over-month growth
- Year-over-year growth
- Period-over-period comparisons
- Regional sales comparison
- Profit performance
- Key business insights
- Interactive dashboard visualization

---

## 🎯 Objective

The main objective is to practice period-over-period comparisons and understand how different regions perform over time.

This project also demonstrates how SQL and data visualization can be used to transform raw business data into meaningful insights.

## 📊 Dataset

A Superstore-style regional sales dataset is used for this project.

The dataset contains:

- Order Month
- Region
- Sales
- Orders
- Customers
- Profit

The project analyzes four regions:

- North
- South
- East
- West

The analysis covers multiple time periods to identify regional growth trends.

---

## 🔍 Analysis Performed

### 1. Regional Sales Analysis

Sales performance is calculated for each region over time.

### 2. Month-over-Month Growth

Monthly sales are compared with the previous month to calculate growth percentage.

### 3. Year-over-Year Growth

Annual regional sales are compared with the previous year.

### 4. Period Comparison

The project compares sales between the beginning and ending periods to identify overall regional growth.

### 5. Regional Performance

Each region is evaluated based on:

- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Overall Growth

---

## 📈 Dashboard

The project includes an interactive dashboard built using **Plotly and Gradio**.

### Dashboard Features

- Region selection

- End date filter
- Total Sales KPI
- Total Orders KPI
- Total Profit KPI
- Regional Sales Trend
- Regional Sales Comparison
- Regional Summary Table

Users can select a region and time period to dynamically analyze the data.
